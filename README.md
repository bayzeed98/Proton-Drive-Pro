# Proton Drive Auto-Share Suite Pro 🚀

একটি শক্তিশালী, সম্পূর্ণ সুরক্ষিত এবং ক্লায়েন্ট-বান্ধব **Proton Drive Bulk Sharing & Lead Dispatcher** অ্যাপ্লিকেশন।

---

## 🌟 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **১০০% সোর্স কোড সুরক্ষিত (Source Code Protection):**
   - AST-লেভেল অবফাসকেশন (`javascript-obfuscator`) দিয়ে সম্পূর্ণ কোড স্ক্র্যাম্বল করা।
   - স্ট্রিং অ্যারে এনক্রিপশন (Base64), কন্ট্রোল ফ্লো ফ্ল্যাটেনিং এবং হেক্সাডেসিমেল আইডেন্টিফায়ার।
   - ক্লায়েন্ট বা যে কেউ `.exe` ফাইল থেকে সোর্স কোড দেখতে বা ডিকম্পাইল করতে পারবে না।

2. **এক ক্লিকে রানযোগ্য সিঙ্গেল `.exe` ফাইল (One-Click Standalone .EXE):**
   - ক্লায়েন্টের কম্পিউটারে Node.js, Python বা কোনো কিছু ইন্সটল থাকার প্রয়োজন নেই।
   - ক্লায়েন্টকে শুধু `dist/ProtonDrivePro.exe` ফাইলটি দিলেই চলবে। ডাবল ক্লিক করলেই অটোমেশন শুরু হবে এবং সরাসরি ব্রাউজারে ড্যাশবোর্ড ওপেন হবে।

3. **ইউজার-ফ্রেন্ডলি মডার্ন ড্যাশবোর্ড (Sleek Web Dashboard):**
   - **রিয়েল-টাইম লাইভ কনসোল (Live Console):** ওয়েবসকেটের মাধ্যমে ব্রাউজারের প্রতিটি অ্যাকশন ও এরর স্ক্রিনে সরাসরি দেখা যাবে।
   - **অ্যাকাউন্টস ম্যানেজার (Accounts Manager):** বাল্ক ফরম্যাটে (`email:password:recovery`) প্রোটন অ্যাকাউন্ট যুক্ত করা ও স্ট্যাটাস ট্র্যাকিং।
   - **টার্গেট লিড ও মেসেজ (Leads & Custom Message):** একসাথে শত শত লিড ইমেইল পেস্ট করা, রিসেট করা এবং সেন্ড/ফেইল্ড লিড CSV হিসেবে ডাউনলোড করা।
   - **পিডিএফ আপলোডার (Drag & Drop PDF):** যেকোনো PDF ড্র্যাগ করে আপলোড ও সিলেক্ট করার সুবিধা।
   - **প্রক্সি ও ব্রাউজার সেটিংস (Proxy & Browser Mode):** ব্রাউজার সামনে দেখতে চাইলে `Visible Mode`, পেছনে চালাতে চাইলে `Headless Mode`, এবং HTTP/SOCKS5 প্রক্সি কনফিগারেশন।

## 🛠️ ক্লায়েন্ট কীভাবে চালাবে? (How Clients Run the App)

1. `dist/ProtonDrivePro.exe` ফাইলটি ক্লায়েন্টকে দিন।
2. ক্লায়েন্ট ফাইলটিতে **Double Click** করবে।
3. সফটওয়্যারটি ব্যাকগ্রাউন্ডে রান হয়ে ক্লায়েন্টের ডিফল্ট ব্রাউজারে ড্যাশবোর্ড ওপেন করে দেবে:
   `http://localhost:3000`
4. ড্যাশবোর্ডে গিয়ে:
   - **Accounts** ট্যাবে গিয়ে প্রোটন অ্যাকাউন্ট পেস্ট করুন।
   - **PDF Upload** ট্যাবে গিয়ে কাঙ্ক্ষিত PDF সিলেক্ট করুন।
   - **Leads** ট্যাবে গিয়ে টার্গেট ইমেইল ও মেসেজ লিখুন।
   - **Dashboard**-এ ফিরে গিয়ে **Start** বাটনে ক্লিক করলেই কাজ শুরু হয়ে যাবে!

## ⚙️ আপনি কীভাবে নতুন করে বিল্ড করবেন? (How to Rebuild)

ভবিষ্যতে যদি কোড বা ড্যাশবোর্ডে কোনো পরিবর্তন করেন, তবে নতুন সুরক্ষিত `.exe` বানাতে:
* সরাসরি **`build.bat`** ফাইলে ডাবল ক্লিক করুন।
* অথবা টার্মিনালে কমান্ড দিন:
  ```bash
  npm run build
  ```
স্বয়ংক্রিয়ভাবে সম্পূর্ণ কোড অবফাসকেট হয়ে `dist/ProtonDrivePro.exe` তৈরি হয়ে যাবে।
